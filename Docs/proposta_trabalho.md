# WORKSHOP: INTRODUÇÃO À ENGENHARIA DE DADOS + DATA WAREHOUSING
## Plano de Trabalho

- Workshop ministrado por 4 pessoas ao longo de 3 dias e aulas com duração de 2 horas e 30 minutos, para apresentação de conceitos introdutórios sobre engenharia de dados, apresentar etapas de trabalho de um engenheiro de dados para construção de uma pipeline de trabalho, criação de rotinas para qualidade de dados e proposição de um projeto prático para criação de um data warehouse.

## Objetivos
- Apresentar conceitos introdutórios sobre engenharia de dados; 
- Discutir sobre processos de coleta, limpeza, acesso, transformação e infraestrutura de dados; 
- Capacitar os participantes, ao fim do workshop, a serem capazes de elaborar uma pipeline de engenharia de dados completa.

### Objetivos específicos:
- Introduzir o público a conceitos de engenharia de dados. Apresentar as responsabilidades de um engenheiro de dados e as etapas principais do ciclo de vida de engenharia de dados, demonstrando como cada etapa costuma ser realizada.
- Apresentar como utilizar o ciclo de vida de engenharia de dados para modelar e construir uma arquitetura robusta; Boas práticas de engenharia de dados; Apresentar desafios enfrentados no ciclo de vida de engenharia de dados.
- Aprofundar um pouco mais sobre cada uma das etapas(Extraction, Loading, Ingestion, Transformation, Serving) do ciclo de vida de engenharia de dados. Apresentando rotinas e frameworks comumente utilizados.
- Propor a realização de uma atividade prática, onde os participantes deverão a partir de uma situação problema proposta, construir do absoluto 0, uma arquitetura capaz de alimentar todo o processo do ciclo de vida de engenharia de dados, utilizando os conceitos aprendidos durante o workshop.

## Programação & Ementa
### DIA 1: Introdução à Engenharia de Dados
- Apresentação do Workshop
- Contextualização a partir de um estudo de caso (A elaborar)
- Responsabilidades, dia a dia, rotinas de trabalho relacionadas
- Ciclo de vida de engenharia de dados
- Desafios enfrentados no cotidiano de um engenheiro de dados

### DIA 2: 
- Apresentar o conceito de Data Warehouse
- Data Warehouse, Data Lake, Data Lakehouse, Modern Data Stack
- Orquestração & DataOps
- Explorar as etapas do ciclo de vida de engenharia de dados:
    - Geração/Coleta
    - Armazenamento
    - Ingestão/Transformação
    - Disponibilização
- Discutir sobre os processos de ETL/ELT:
    - Apresentação prática dos conceitos utilizando notebooks e ferramentas relevantes


### DIA 3:
- Realização de projeto prático:
    - Apresentação de contextos práticos para que os participantes elaborem uma solução de engenharia de dados para solucionar o problema.
